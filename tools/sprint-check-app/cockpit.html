Factory

GitHub workflow · works today, needs only gh
  1. Send. A ticket goes to your repo as an issue (▶ Start › GitHub · new issue in the worktree picker, tkt send-issue), or an issue labelled canon comes in as a ticket (GitHub Sync, tkt sync-issues).
  2. Work. An agent's cloud session works it on your subscription: it works on a new branch, pushes it and opens a PR.
  3. Guard. The issue tells the session never to push main or force-push. A private repo on a free GitHub plan cannot enforce that with a branch rule, so this text is the only guard.
  4. Return. After it exports, the session stops; it never merges. Its results come back with Import results (tkt import-results).
  5. Merge. The PR lands with Check & merge (tkt merge-pr).
Checks
Canon never stores a GitHub token or logs you in. It runs gh as you, reads the answers, and tells you the command to run yourself.
Intake · issues become tickets
  1. Label an open issue on origin with the label below.
  2. Sync. Press GitHub Sync on the board (tkt sync-issues). A preview comes first.
  3. Tickets. Each labelled issue that no ticket links to yet becomes a local ticket. Sync only reads GitHub.
The label admits an issue but does not vouch for text edited after it was labelled: read the preview.

Canon Cockpit
one window for every canon project · local · no account
One window

Launch canon once. Running it again just focuses this window — everything opens inside it, no more a browser tab per project.

Projects

Register a project folder with + Add Project; each card shows when it was updated and its ticket count. Click the green › to open a project in a tab.

Two projects at once

Right-click a project tab to open it beside or below the tab you are on. Drag the divider (or focus it and use the arrow keys) to resize, double-click it to reset. ctrl+. then v (beside) or - (below) does the same with the tab you came from (shift for the next tab in the strip); o moves to the other pane, s swaps them, r switches beside and below, and u closes the split. Projects, Factory and Admin still show full size; Skill Eval opens inside its project's pane.

Tabs

Open projects become folder-named tabs beside the pinned Projects tab; close a tab with its ✕.

Admin

The Admin view shows the cockpit daemon (health, version, uptime, Restart) and every active agent session across all projects.

Update

In a terminal run canon update. It brings canon up to date and refreshes your registered projects (about 20 seconds each on Windows). On Windows the daemon has to be stopped first: if canon update says it is still running, use Admin › Stop Daemon (or run canon stop), then run canon update again. When it finishes, run canon to start the Cockpit.

Theme

◐ Theme in the footer: Mode (System, Light or Dark; System follows your computer's setting) and the theme for it (under System, one for light and one for dark). Besides Canon Dark and Canon Light there are Catppuccin Mocha and Latte, Tokyo Night, Nord, Dracula and Gruvbox Dark (credits in THEMES.md). Hover a theme to preview it; click to keep it. Hover the button to see the theme in use. It applies to the shell and every open board, and is remembered. Add your own theme as a file in ~/.canon/themes/ (Open themes folder at the bottom of the menu creates it with an example); a file that breaks a rule is listed there with the reason, and a hard-to-read theme is marked Low contrast (docs/custom-themes.md).
