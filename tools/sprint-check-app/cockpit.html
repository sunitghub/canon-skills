Canon Cockpit
one window for every canon project · local · no account
One window

Launch canon-cockpit once. Running it again just focuses this window — everything opens inside it, no more a browser tab per project.

Projects

Register a git repo with + Add Project; each card shows when it was updated and its ticket count. Click the green › to open a project in a tab.

Tabs

Open projects become folder-named tabs beside the pinned Projects tab; close a tab with its ✕. The embedded board is read-only in this phase.

Admin

The Admin view shows the cockpit daemon (health, version, uptime, Restart) and every active agent session across all projects.

Theme

The footer toggle flips dark / light and applies to the shell and every open board.

Coming next

Editing tickets from inside a project tab (writes) and running an agent session in-tab arrive in upcoming phases.
