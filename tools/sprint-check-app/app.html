What's inside


      

        
Kanban board—your .tickets/ folder as a live board.

        
Four columns: Open, In Progress, Done, Discarded. Drag cards to update status instantly. Auto-refreshes every 8 seconds.

        

          drag-to-move
          auto-refresh
          light & dark
        

      


      

        
Ticket completeness—readiness baked into every card.

        
Ready, unchecked, incomplete, needs-doc, and needs-signoff states show whether Acceptance has Criteria/Test Plan items, no unchecked boxes including ## QA, Plan has real ## Approach notes, and Plan ## Sign-off is checked.

        

          acceptance gate
          QA + sign-off
          inline warnings
        

      


      

        
Sprint docs—board-created Acceptance and Plan, plus workflow artifacts.

        
Create and edit acceptance.md and plan.md from the board. The agent also writes research.md, eval-report.md, summary.md, and ## Wrapup Gates during the sprint flow.

        

          acceptance.md
          plan.md
          workflow artifacts
        

      


      

        
Commit intelligence—click any commit to see what it touched.

        
Direct ticket ID matches show first. When no ID is present, semantic keyword matching surfaces the most likely related ticket.

        

          ID linking
          keyword fallback
          file diff
        

      


      

        
Create from the board—new tickets without leaving the browser.

        
The title auto-detects type (feature, task, bug, chore, epic). Set priority, add a description, hit Create — the ticket appears in .tickets/ immediately.

        

          type detection
          priority
          instant
        

      


      

      
See it in action


      

        Board overview
        

          
          
The full kanban board — four columns, sidebar with git context, and the ticket count stats in the header.

        

      


      

        Ticket detail & docs
        

          
          
          
Click any card to open the detail modal. Switch doc tabs to read or edit board docs without leaving the board; agent-written workflow docs appear as extra tabs when present.

        

      


      

        Ticket completeness
        

          
          
Every card shows its readiness state. Red means Acceptance is incomplete or has unchecked boxes; amber means the next doc or Plan Sign-off is missing before close.

        

      


      

        Commit intelligence
        

          
          
Click a commit hash in the sidebar. See the full message, changed files, and which ticket it most likely belongs to.

        

      


      

        Drag to move & create tickets
        

          
          
          
Drag any card to a new column to update status. Click + New to create from the board — the title suggests a type automatically.
