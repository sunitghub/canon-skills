# Third-party notices

The cockpit daemon (`tools/cockpit-daemon`, fetched by `tools/fetch-daemon.sh` as a release asset on every platform: `tools/cockpit-daemon-win.exe` on Windows, the prebuilt binary on macOS/Linux; the Windows board and headless helper are fetched the same way and are built from canon's own source with the Go standard library only) is built from canon's own source plus the Go modules and the vendored front-end files below. Each Go module's license text follows, copied verbatim from the module at the version pinned in `tools/cockpit-daemon/go.mod`. The daemon embeds `tools/cockpit-daemon/web`, which includes xterm.js (`xterm.js`, `xterm.css`) and its fit add-on (`xterm-addon-fit.js`) under `web/vendor/`; their license text follows the Go modules, copied verbatim from the npm packages whose files they are byte-for-byte. canon's own license is in `LICENSE`. `tests/fetch-daemon.sh` fails when a module in `go.mod`, or a `.js` or `.css` file under `web/vendor/`, is not named here.
