# Third-party notices

canon's program `canon-go`, the board and the Cockpit daemon in one binary (source `tools/canon-go`, fetched by `tools/fetch-daemon.sh` as a release asset on every platform: `tools/canon-go-win.exe` on Windows, `tools/canon-go-bin/canon-go` on macOS/Linux), is built from canon's own source plus the Go modules and the vendored front-end files below (the daemon part uses them; the board part uses the Go standard library only). Each Go module's license text follows, copied verbatim from the module at the version pinned in `tools/canon-go/go.mod`. The daemon embeds `tools/canon-go/internal/daemon/web`, which includes xterm.js (`xterm.js`, `xterm.css`) and its fit add-on (`xterm-addon-fit.js`) under `web/vendor/`; their license text follows the Go modules, copied verbatim from the npm packages whose files they are byte-for-byte. canon's own license is in `LICENSE`. `tests/fetch-daemon.sh` fails when a module in `go.mod`, or a `.js` or `.css` file under `web/vendor/`, is not named here.
