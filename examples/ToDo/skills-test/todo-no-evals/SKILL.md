description: Adds priority prefixes to todo item text. Use when the user wants to mark a ToDo item as high, medium, or low priority.
---

# ToDo priorities

Prefix the item text with `[P1]` (urgent), `[P2]` (this week), or `[P3]` (someday). Keep the rest of the item as written, and never put more than one prefix on an item. If the user gives no priority, ask which of the three applies instead of guessing.
