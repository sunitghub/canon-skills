# t-2912: which suites the pre-commit hook runs for a staged path (read by tools/covering-suites.sh; its header has the rules).
# A staged path with no row runs the full suite, so a hub (tools/sprint, tools/tkt, tools/platform-lib.sh, tools/skills.sh,
# tests/helpers.sh, scripts/test.sh, this file) never gets one: nearly every suite runs them. Every scoped run adds
# tests/pre-gate-suites.txt (caps, the release zip, doc parity). The close's full-suite stamp stays the gate.
# `@named`: the suites whose source names the path. Every row is checked on every commit: its labels must be --list labels.
